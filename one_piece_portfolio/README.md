# Novin Kumar — One Piece Inspired Portfolio

## Files
- `index.html` — portfolio structure and content
- `style.css` — Grand Line / wanted-poster visual theme, responsive styling
- `script.js` — GSAP loader, custom cursor, and ScrollTrigger animations

## Run locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the GSAP CDN scripts.

## Before publishing
- Replace `novinkumar22@email.com` with your real contact email.
- Check the LinkedIn URL and update it if needed.
- Update project links/screenshots if you want each project card to open a live demo or repository.

The design uses original CSS styling and One Piece-inspired nautical/pirate motifs; it does not include official anime artwork.
